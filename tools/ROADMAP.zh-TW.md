# 生成器路線圖：一步一步把遊戲因素堆上去

原則（2026-11-25 與使用者確認）：**先把遊戲的計算因素補齊，再精修權重**。
權重只能學到生成器「有試過」的東西；因素還沒補齊就精修權重，之後每補一個因素就要重學一次。
每次生成器改版（GENERATOR_VERSION），自我對弈會把所有組合重跑一遍（兩台電腦約 2～3 晚），
所以盡量把幾個因素一起放進同一版。

## 已完成

| 版本 | 內容 |
|---|---|
| 1 | 技能、模板裝備、武器、5 個輔助寶石、昇華、天賦樹、光環 |
| 2 | 多段技能的層數推論、雙持武器、只留會造成傷害的技能、資料庫壓縮 |
| 3 | 詛咒／印記／曝露；光環和詛咒在天賦樹之前先選（看得到保留和屬性需求） |
| 4 | **天賦精通**（每個精通 1 點，與天賦一起比較）、**萬神殿**（主神、次神） |
| 5 | **功能藥劑**（藥劑欄 2～5，品質 20、無詞綴、視為常駐）；**暴擊球／狂怒球／耐力球**（有來源才開：陷阱、地雷、圖騰、召喚物的來源要有對應技能，暴擊來源要會暴擊，只靠格擋的來源要格擋率 ≥ 20%，只靠擊殺的來源打王不算）；Enduring Cry 加入光環候選；**暴擊路線**（暴擊裝備、排除 Precise / Resolute Technique 與 Elemental Overload）加入自我對弈，排在一般組合之後 |
| 6 | **天賦樹珠寶**：6 種模板稀有珠寶（攻擊、法術、暴擊、召喚物、持續傷害、防禦，皆含 7% 最大生命），在第一個插槽找出最適合的種類，之後「點插槽＋放珠寶」和天賦一起比每點效益；天賦樹完成後每顆珠寶再試換種類 |
| 7 | **防護技能、魔像、戰吼**：Steelskin／Molten Shell 最多一個（擋大招前開）、魔像一隻、戰吼最多三個（PoB 依冷卻平均）；Blood Rage 加入增益；Immortal Call 與位移技能（Phase Run 等）不用，因為 PoB 會當成常駐而高估 |

已確認不需要另外做：
- 威嚇、近期擊中、近期攻擊：PoB 會依來源與主技能自動判定。
- 格擋、法術壓制、閃避：PoB 的 Total EHP 已經計入，評分有用到。
- 強盜任務：維持「全殺」（多 2 點天賦點）。

## 接下來（依序）

1. **深淵珠寶、星團珠寶**（天賦樹一般插槽已在第 6 版完成）。
2. 位移技能與短暫增益（Phase Run、Immortal Call）：需要先能算持續率才加入。
3. **項鍊塗油、頭盔附魔**。
4. **傳奇裝備**：先挑會改變玩法的（轉換、技能機制）。
5. 因素大致補齊後：**組合權重**（「已經有 A 時，B 值多少」）→ 再試權重引導搜尋
   （2026-11-25 測過平均權重引導：少試 37%，但有 2/3 組變差，因為成套搭配被刪掉）。
6. 細化假設：藥劑實際持續率、球的實際維持率（目前都視為常駐／滿球）。

## 驗證（每個階段都做）

1. 資料內部：保留 20% 模擬不學，檢查權重預測（`python tools/weights.py check`）。
2. 對照作者 build：同樣裝備下（`--gear-from`），生成器能否接近或超過作者。
3. 實際遊玩：挑幾個生成的 build 進遊戲測，確認過的結果記成「已驗證」。
