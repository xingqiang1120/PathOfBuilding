# 實戰驗證清單（使用者進遊戲測生成器的 build）

三種驗證裡的第三種：保留資料、真人 build 之外，**實際玩**。目的是找出 PoB 算得出來、但遊戲裡不成立的假設，
把它變成生成器的規則（派給 home）。使用者的遊玩經驗優先於 PoB 的預設值。

## 流程
1. **阿福挑 build**：從最新版生成器的產出挑一個，給你 PoB 匯入碼和「這個 build 假設了什麼」（例如：充能永遠滿、
   藥劑永遠開著、詛咒永遠掛著、守衛技能被打就開）。
2. **你照著做出角色**（或用現有角色接近的配置），進遊戲測下面的項目。
3. **回報給阿福**：照下面的表格講就好，不用很精確，例如「大概」「感覺」都可以。
4. **阿福整理**：記進遊玩紀錄（play_log），差很多的假設寫成修正規則，派給 home 改生成器；你確認過的設定才存進 build。

## 測什麼

### A. 角色面板（打開角色資訊，跟 PoB 比）
| 項目 | PoB | 遊戲 | 差多少 |
|---|---|---|---|
| 生命／能量護盾 | | | |
| 火／冰／電／混沌抗 | | | |
| 護甲／閃避／格擋 | | | |
| 技能面板 DPS（遊戲裡的數字） | | | |

差超過 10% 就記下來：通常是 PoB 的設定（Config）和實際狀態不一樣。

### B. 打王（挑一隻你熟的王，例如 T16 地圖王或先知）
- 大概幾秒打死？跟你同裝備等級的其他 build 比，快還是慢？
- 有沒有被秒？被什麼打死（物理、元素、混沌、持續傷害）？
- PoB 假設的狀態實際做得到嗎？（充能有沒有滿、藥劑能不能一直開、詛咒有沒有掛上）

### C. 清圖（跑 3～5 張一般地圖）
- 清圖速度 1～5 分（5 最快）、死幾次、被什麼打死。
- 魔力或生命會不會不夠用（技能放不出來、喝藥頻率）。
- 移動手感（太慢、卡怪）。

### D. 你覺得不對勁的地方
任何「PoB 說可以但遊戲裡不行」或「遊戲裡比 PoB 好」的事都記下來。這些最有價值。

## 回報格式（直接打字給阿福就好）
> 測試 build：Smite／Slayer v13
> 面板：生命 PoB 5,011 遊戲 4,800；抗性都滿；DPS 遊戲面板 1.2 億
> 打王：先知 40 秒，被冰的打死一次
> 清圖：4 分，死 1 次（混沌持續傷害）
> 不對勁：Power charge 打王時常常掉光
